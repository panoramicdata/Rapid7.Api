# Changelog

## 3.0 (first release)

- A typed client for every operation of the InsightVM Security Console API v3 (330), the Cloud Integrations API v4 (13)
  and the Bulk Export GraphQL API (5), with Bulk Export create-and-wait helpers, key-free downloads and typed Parquet
  records.
- Live verification is pending: the integration tests are written but have not yet run against a live console.
